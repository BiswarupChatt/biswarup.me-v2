# Biswarup.me

Personal portfolio website for Biswarup Chatterjee, built with React, TypeScript, Vite, and Material UI.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run preview` previews the production build locally.

## Stack

- React 19
- TypeScript
- Vite
- Material UI
- React Router

## Local Setup

```sh
npm install
npm run dev
```
